# proyecto-after
Este proyecto consiste en la creación de un personaje con rig facial y corporal realizado en Adobe After Effects, utilizando diferentes recursos gráficos y múltiples versiones del proyecto para documentar el proceso de desarrollo.

El objetivo principal del trabajo es experimentar con:

Sistemas de rigging en After Effects.
Controladores para animación.
Organización de proyectos audiovisuales.
Separación de assets y renders.
Flujo de trabajo iterativo mediante versiones.
